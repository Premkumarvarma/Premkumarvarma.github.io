## Deploy free with GitHub Pages
1. Create a repository, e.g. `premkumar-portfolio`
2. Upload everything inside this folder
3. GitHub repository → Settings → Pages
4. Source: Deploy from a branch
5. Branch: main
6. Folder: /(root)
7. Save

Your public portfolio will be:
https://Premkumarvarma.github.io/premkumar-portfolio/
